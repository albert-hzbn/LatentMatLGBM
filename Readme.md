# LatentMatFusion

**LatentMatFusion** is a desktop machine-learning application for predicting mechanical and thermodynamic properties of crystalline materials. It combines a convolutional **Autoencoder** for compressing VASP CHGCAR charge-density data with **gradient-boosted tree models** (GBM / LightGBM) trained on the resulting latent features fused with Magpie compositional descriptors.

Two prediction modes are available:
- **CHGCAR mode** — load a VASP CHGCAR file; the encoder compresses the charge density into a 128-element latent vector, which is combined with Magpie features and fed to a GBM model.
- **Magpie-only mode** — enter a chemical formula; prediction uses only Magpie compositional features (no CHGCAR required). Useful for rapid screening.

A **Latent Space** tab allows loading pre-computed latent vectors (`.npy`) and reconstructing the corresponding CHGCAR file via the decoder model.

| Formation energy | eV/atom | GBM + MagpieOnly |
| Debye temperature | K | GBM + MagpieOnly |

## Architecture Overview

```
CHGCAR file
    |
    v
Autoencoder Encoder  (128x128x128 -> 128-D latent vector)
    |
    +-- Latent features  --+
    |                       +-- PCA reduction -> GBM / LightGBM -> predicted property
    +-- Magpie features  --+

Chemical formula  (Magpie-only mode)
    |
    v
Magpie ElementProperty features -> GBMMagpieOnly -> predicted property
```

- The **encoder** is a 3-D convolutional neural network trained on 6,059 VASP CHGCAR files. Input volumes are normalised and padded/resized to 128x128x128.
- **Magpie features** are 132-dimensional compositional descriptors generated by `matminer.featurizers.composition.ElementProperty.from_preset("magpie")`.
- One **GBM model**, one optional **LightGBM model**, and one **GBMMagpieOnly model** are stored per property under `model/current/<property>/`.

## Installation

This project requires **Python 3.11**. All large model files (`.pkl`, `.h5`, `.npy`) are tracked with **Git LFS**; make sure Git LFS is installed before cloning.

```bash
git lfs install
git clone https://github.com/albert-hzbn/LatentMatFusion.git
cd LatentMatFusion
```

### Linux / macOS

```bash
# Install system dependencies (Ubuntu/Debian)
sudo apt update
sudo apt install python3.11 python3.11-venv python3.11-tk

# Create and activate virtual environment
python3.11 -m venv .venv
source .venv/bin/activate

# Install Python dependencies
pip install --upgrade pip
pip install -r requirements.txt
```

### Windows

Download **Python 3.11** from [python.org](https://www.python.org/downloads/) and check **"Add Python to PATH"** during installation. `tkinter` is bundled by default.

```cmd
py -3.11 -m venv .venv
.venv\Scripts\activate

python -m pip install --upgrade pip
pip install -r requirements.txt
```

## Usage Guide

### Prediction Tab — CHGCAR Mode

1. Select **"CHGCAR"** as the prediction mode.
2. Click **"Browse"** and load a VASP CHGCAR file.
3. Optionally click **"Visualise 3D"** to inspect the charge density (requires PyVista).
4. Click **"Predict"**. The encoder compresses the charge density; predictions for all five properties are shown in a results dialog.

### Prediction Tab — Magpie-Only Mode

1. Select **"Magpie Only (Formula)"** as the prediction mode.
2. Type a reduced chemical formula in the text field (e.g. `Fe2O3`, `SrTiO3`, `Al2Cu`).
3. Click **"Set Formula"** to validate the input, then **"Predict"**.
4. Results are displayed for all available models. Properties with no MagpieOnly model show **N/A**.

> Note: `youngs_modulus` does not currently have a MagpieOnly model and will display N/A in this mode.

### Latent Space Tab

1. Click **"Load Latent (.npy)"** and select a pre-computed latent vector from `data/latent_data/`.
2. Click **"Load Structure (POSCAR)"** and select the corresponding structure file from `data/structures/`. The unit cell parameters are displayed.
3. Click **"Export to CHGCAR"**. The decoder reconstructs the 128x128x128 charge density volume and writes a valid VASP CHGCAR file.

### Batch Encoding New CHGCAR Files

Place your CHGCAR or `.npy` files in `data/compressing/input/`, configure the paths at the top of `data/compressing/encode.py`, then run:

```bash
python data/compressing/encode.py
```

Latent vectors are saved as `.npy` files in `data/compressing/output/`.

## Model Files and Git LFS

All `.pkl`, `.h5`, `.npy`, and `.zip` files are stored in Git LFS (configured in `.gitattributes`). If model files appear as small text pointer files after cloning, run:

```bash

```

## Notes

- Always activate the virtual environment before running the application.
- If you encounter `tkinter`-related errors on Linux, ensure `python3.11-tk` is installed.
- CHGCAR files should be generated using standard VASP settings (`LCHARG = .TRUE.`).
- The encoder was trained on 128x128x128 grids; input volumes are automatically resized or zero-padded to this shape.
- Tested on **Ubuntu 22.04** and **Windows 10/11**.
